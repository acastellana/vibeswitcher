# Open items from the four evaluation reports, re-checked on 2026-10-19

This re-checks the four reports of 2026-10-17 (`engineering.md`, `runtime.md`, `ux.md`, `security.md`) against
project-lead at **16db1c0**. It covers every item in their "Top N to fix first" lists (with "next after these" and
"next in line") and every P0/P1 finding. There are **65 ids**. For each one it gives a verdict:

- **fixed**: the commit and task are named, along with the code path and the test that covers it.
- **partly**: what is done and what remains, with today's file:line.
- **open**: today's file:line, a reproduction where one was safe, and a proposed task contract.

A ranked list of open work comes at the end. Its first 8 items are the proposed next wave.

## How this was checked

- **Where fixes are recorded.** Fixes were traced through `git log --grep` / `-S` and through the task contracts in
  `.vibeswitcher/board.json`. Those contracts are the lead's record of every merged task; this document cites them by
  task slug. The decisions log (`.vibeswitcher/decisions.md`) was used too. A contract that claims an item was never
  taken as proof: every verdict rests on today's code.
- **Tests.** Every test named here was checked to exist at 16db1c0 (grep of `Tests/`). Every commit sha was checked
  with `git cat-file`.
- **No swift build or swift test was run.** The Mac's 1-minute load stayed between 170 and 265 the whole time, and the
  task allows no load. So "test: X" means the test exists and asserts the behaviour. It does **not** mean the test was
  run today.
- **Reproductions.** Each was a standalone script or a `swiftc` build of a **verbatim copy** of the source function,
  run on scratch data in the session's scratch folder, together with read-only `ps` sampling of the installed app. The
  installed build dates from 2026-10-19 12:07. Timings measured at this load are inflated; the ratios still hold.
- **Never touched:** the real app, the session host, sessions, the Keychain, phone pairing, signing identities and
  `~/.vibeswitcher`.
